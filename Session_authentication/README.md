# Session authentication

## Description

This project aims to implement a session-based authentication system in Python.

The goal is to understand how authentication works on the server side, especially the use of sessions and cookies in a REST API.  
Even though, in real-world development, authentication is usually handled by dedicated libraries or frameworks, this project is useful for learning the basics by building it manually.

## Background Context

In this project, we will learn how to:

- understand what authentication means
- understand what session authentication means
- understand what cookies are
- send cookies
- parse cookies

## Learning Objectives

At the end of this project, I should be able to explain:

- what authentication means
- what session authentication means
- what cookies are
- how to send cookies
- how to parse cookies
